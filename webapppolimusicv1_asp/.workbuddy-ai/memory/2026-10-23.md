# 2026-10-23 — PoliMusic (ASP clásico + SQL Server)

## Construido
Aplicación web tipo Spotify en **ASP clásico/VBScript + HTML/CSS/JS vanilla**, BD `BDD_PoliMusic` en SQL Server (localhost, usuario `sa`).

- `includes/`: `config.asp`, `db.asp` (conexión OLE DB `MSOLEDBSQL19` + helpers `NewCmd/AddStr/AddInt/ExecRs/SqlRs`), `auth.asp`, `icons.asp` (SVG inline), `layout_top.asp`, `layout_bottom.asp`, `queries.asp`, `tracklist.asp`, `admin_helpers.asp`.
- Páginas en la **raíz del sitio**: `login.asp`, `index.asp`, `logout.asp`, `home.asp`, `playlists.asp`, `artists.asp`, `albums.asp`, `api-play.asp`, `admin-songs.asp`, `admin-users.asp`, `admin-artists.asp`, `admin-albums.asp`, `admin-playlists.asp`.
- `assets/css/app.css` (~53 KB) sistema de diseño con dos temas, `assets/js/app.js` (~23 KB) reproductor global, modales, búsqueda, toasts, likes en localStorage.

## Decisiones técnicas clave
- **Registros desconectados** (`rs.CursorLocation = 3`, `rs.Open cmd, , 3, 1`) para evitar "Query timeout expired" con múltiples recordsets abiertos.
- **Todas las páginas ASP en la raíz**: IIS bloquea `enableParentPaths` en `web.config` (`overrideModeDefault="Deny"`), así que `../includes/` provoca ASP 0131. No volver a crear subcarpetas con includes relativos.
- Contraseñas: soporte **texto plano y SHA1** (`HASHBYTES('SHA1', ...)`), porque el seed trae `username1` hasheado.
- Roles vía `Session("user_type")`: `0` normal (tema lavanda), `1` admin (tema dorado). CRUD solo admin, con guardas de auto-eliminación y "último admin".
